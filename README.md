# isods-test

This repo is for ISODS entrance test. The repo contains the following files:

- **crawl.ipynb**: script to crawl data from vbpl, with full HTML, property, related, history and PDF (PDF script is run in vbpl_pdf.ipynb).
- **vbpl_pdf.ipynb**: script to get the PDFs.
- **vector_search.ipynb**: script to ingest the data into Chroma, perform semantic search and some observations.

For the data, it can be found in this [drive](https://drive.google.com/drive/folders/1KW8quW-SIthBFU8LmTndR-fx-TUijHR_?usp=sharing)
